# 几何诊断结论：平面关系误差与事件预测是两个问题

日期：2026-10-09。描述性诊断，不新增训练或仿真。

## 当前结论

**当前连续位置误差主要受目标—盘平面关系估计影响；事件判断还有独立于这部分感知误差的残余问题。** 不能把两者再合并为“视觉不够好”。

| 真实值修复范围 | 未来目标—盘误差 |
|---|---:|
| 不修复 | 28.79 mm |
| 只修复目标—盘XY | 9.89 mm |
| 只修复目标—盘Z | 28.71 mm |
| 修复所有关系 | 9.51 mm |
| 全部真实状态 | 9.27 mm |

在22个不同起点、9场景的scene宏平均中，当前目标—盘X/Y/Z绝对误差为16.95/16.35/7.72 mm，并有+12.86/+8.68/+4.50 mm的带符号偏差。这里XY指世界系平面，不是图像像素平面。

这支持优先定位平面几何误差，但不证明未来任何场景都不需要精确高度。绝对未来误差包含起点偏差；真值修复直接减少起点偏差，因此不能把约19 mm的降幅全归为动力学预测更好。候选差分几乎不变，也不代表动作选择已经正确。

## 几何修复没有消除事件错误

| 输入 | On发生 TP/FP/FN | 持有起点release TP/FP/FN |
|---|---:|---:|
| 自然预测 | 3/12/4 | 4/2/2 |
| 全部真实状态 | 4/6/3 | 4/2/2 |

真实状态改善了部分On误报，但并没有变成可靠事件预测。真正持有→释放只有6条正例、3场景，不能据此估计稳定总体精度。当前模型由连续位置损失和事件辅助损失联合训练，不能把事件残余误差直接归因为接触不可见。

此前最小状态消融已试过接触输入，它也没有一致修复事件判断；因此不建议简单重复“加接触特征再训练”并期待问题自然消失。需要分开检查事件覆盖、标签时窗与错误类型，以及连续状态预测和事件预测的监督是否匹配。

## 目标与盘的诊断要保留边界

辅助uv/depth头经相机逆投影后，目标碗位置误差58.17 mm，盘13.74 mm。在该辅助路径中只修复碗，可将相对关系误差62.41降到13.74 mm；只修复盘仍为58.17 mm。

这提示辅助头的移动目标定位值得优先检查。但主头直接输出相对关系，它没有可唯一分解的两个独立位置。不能据此声称主头的28.79 mm全部来自碗，也不能贸然用辅助头的显式3D重建替换主头——目前该路径反而更差。

## 下一步应如何收敛

先把后续感知实验限制为“移动目标与盘的平面相对位置”，不要同时改高度、接触、动力学和控制。优先做旧场景内部的目标区域观测上限对照，区分目标是否找错、全图读出是否丢失局部信息，再决定是否值得训练新的定位/记忆模块。真值区域只能作为上限，不可伪装成可部署输入。

事件分支独立保留为未解决问题；在真正释放事件仍只有3个开发场景时，不启动学习式override。后续事件实验应有明确的错误类型和场景支持目标，避免把更多重复分支当成独立证据。确认集保持封存。

这轮没有因为误差诊断选择新模型、调整阈值或追加数据。两个针对性测试通过，21组桥接指标复算通过，自然及全真值输入均复现原结果，辅助头投影逆变换验证通过。没有重跑全仓库套件。
