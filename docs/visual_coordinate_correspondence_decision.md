# 显式视觉—坐标对应：暂不启动三维训练，先建立可见对应证据

日期：2026-10-09。依据本轮旧13场景P0–P2实际诊断，**P3决定：NO-GO_NEW_3D_CORRESPONDENCE_TRAINING**。P4未执行。本决定针对当前监督与几何方案，不是否定显式几何，也不阻止必要的旧数据诊断。

第二只碗的主要表型是平面空间映射失准；完全身份交换仅解释约3%的位置误差。模型对RGB和碗2区域有响应，但未形成可靠定位。单中心加fit高度先验即使用GT二维位置仍有71mm误差；现成预测UV接该求解器为174mm。已知CAD多点PnP在0.5px噪声下可达约23mm，但使用的是GT标注的、身份明确的8个模型点，尚未证明这些点可从当前RGB稳定观测。

## 候选路线比较

以下成本为相对实现/数据需求判断，不是测得GPU时间。全部路线仅允许旧13场景及其合法派生信息。

| 路线 | 数学/物理可行性与误差针对性 | 监督及部署输入 | 成本与泛化风险 | 可解释性、下游价值与当前判断 |
|---|---|---|---|---|
| A 直接world位置回归，加强局部监督 | 不需要显式求解深度，但仍需学习成像与空间映射；可针对全图压缩问题 | 现有world标签齐备，区域监督只覆盖3对象；自然RGB/proprio可部署 | 相对低；小scene数、位置先验与槽位混淆仍在 | 必要对照；不能未经受控比较就认为扩大网络会修复 |
| B 对象区域/轮廓或关键点，再几何求解 | 最能拆分“在哪里”与“深度/尺寸”；单中心平面法对变化高度不充分，已知尺寸多点法有条件成立 | 需可在RGB辨认的点/轮廓、尺度与相机契约；训练时GT监督可用，部署不得提供GT深度/身份 | 中等；精细对应标注与遮挡处理是主要新增工作；低分辨率与对称点歧义有风险 | **推荐的主研究路线，但三维训练暂缓**；先证明自然可见对应能达到有意义精度 |
| C 稠密物体坐标/实例对应 | 多点几何约束充分时可解；标准化物体坐标还要恢复尺度和位姿 | 需新像素级3D对应、身份/对称性处理；原NOCS的深度条件不能直接继承 | 高于本轮资源合理范围；少量scene容易记住外观/布局 | 当前不优先，未显示比B必要 |
| D 仅身份、可见性或一致性约束 | 有助于管理未知和跟踪；完整交换与闭合误差太小，无法单独解释主误差 | 部分mask可用，持久自然身份尚未验证 | 低至中；同外观实例历史歧义仍可能存在 | 作为B的可靠性条件，不作为独立修复主线 |
| E 改进观测、分辨率、时序或覆盖 | 原128px比当前64px保留更多采样；历史可能帮助遮挡，不能保证消除深度歧义 | 可先使用现有旧原始RGB；新深度/多视角不属于已验证部署输入，新scene本轮禁止 | 中；需要固定输入比较，不能混入新场景后宣称架构收益 | 若B在原128px也无法标出稳定对应，再优先改变观测条件；不立即采集新数据 |

## GO条件逐项判断

| 条件 | 本轮判断 |
|---|---|
| 主要误差得到一定隔离 | 部分满足：平面失准、先验回缩；身份完全交换与完全不可见不是主解释。容量、数据与局部观测仍有混杂 |
| 所选几何链有非平凡证据 | 条件性满足：固定高度对象的射线法有效；CAD多点法有数值敏感性结果。尚无适用于所有碗状态的自然对应链 |
| 所需监督在合法数据内可获得 | world/相机/mesh已有；自然可辨认的多点身份、轮廓完整性及其余对象mask尚未验证，**未满足** |
| 与旧辅助方案区别可检验 | 满足设计层面：让几何成为必要推断路径，单独测2D、深度/尺度与3D；尚未实施新的检测器 |
| 公平场景隔离 | 可沿用旧3折；只是内部开发，不是独立确认 |
| 新训练核心指标与停止线冻结 | 本轮只冻结诊断输入与噪声方案，未冻结具体新检测器、标签与预算；**未满足** |

因此不启动新的全对象坐标训练，不用小幅单对象改善或oracle结果补签GO。没有调用新的encoder、事件模型或controller。

## 下一项最小必要工作

在现有旧13场景中建立**原128px可见轮廓/关键点监督可用性检查**，覆盖两个碗、盘、cookies和ramekin：

- 明确每个几何点的物理定义，区分body原点、可见质心、轮廓与模型点；对碗的轴对称性采用可辨认、与目标位置有关的定义，不强制猜不可见的偏航身份。
- 对现有图像检查可见性及标注重复性，保留看不见/无法唯一对应的样本；不能用GT投影点存在就称它可从图像观察。
- 若用静态重渲染生成标签，先逐帧确认与原RGB对齐；它只生成监督，GT深度和物体姿态不能进入自然推理。
- 将该观测精度代入已验证几何链，报告不同支撑高度、抬起及遮挡条件下的误差；若所有有用精度都依赖不可观测顶点或测试帧真实高度，则继续NO-GO。

通过这一检查后，再另立一个小规模预注册：主路线B与A的同输入直接回归对照；保留原独立/共享模型与无图像基线作为历史参照。主比较仍是原15关键边均值、每帧最坏关键边、全部5对象与逐场景分布，不能只看碗2；预算、seed、分辨率、额外监督与停止阈值在训练前冻结，不在本报告凭空承诺增益。

只有可信定位改进后才考虑固定事件读出；真实状态下仍有事件误差，几何改善不能替代事件验证。原9开发与40确认本轮保持未访问；后续泛化确认需在模型与输入契约冻结后单独设计。
