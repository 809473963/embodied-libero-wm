# 扩展动作后果采集：科学复核与剩余瓶颈

日期：2026-10-07。

**冻结模型在扩大动作扰动后仍表现出连续关系预测优势，但事件覆盖、近不变后果的误预测和独立场景泛化尚未解决。** 本轮没有重训，正信号来自此前冻结模型对新分支后果的预测，不是用本批标签拟合后的分数。

## 完成与验证

363次运行（含3次技术preflight）、43,416控制步，采集耗时3,241.79秒（54.03分钟）。20个旧场景、40个固定时刻、360条H8分支，其中356个不同的anchor内动作计划。同步保存初始帧及anchor前10步到H8末端的RGB/proprio和完整前缀物理记录。

采集、接触重建、标签复算、同anchor历史一致性均通过。本次再次验证冻结文件和360条原始分支哈希、analysis哈希，并从保存预测复算6组模型×分区指标，逐项一致。未运行新仿真、训练或全仓库测试。

## 连续关系预测的证据增强了

开发来源为10个旧init34场景，每场景2时刻×9动作，共180分支、160组相对A0的对照。init31另列为已暴露拟合来源，不混入以下成绩。

| 指标（mm） | 不变基线 | 无动作模型 | 动作模型 |
|---|---:|---:|---:|
| 目标—盘位移误差，按场景宏平均 | 17.857 | 10.892 | **8.154** |
| 目标—夹爪位移误差，按场景宏平均 | 21.729 | 15.937 | **11.031** |
| 所有候选对的后果差分误差 | 7.576 | 7.576 | **5.936** |
| 真实差异>1mm层的差分误差 | 14.230 | 14.230 | **9.511** |

相对无动作模型，前两项改善25.1%和30.8%；每项分别在8/10场景改善。>1mm候选差异现在有85对、覆盖10场景，较上一批3对的支持更广，但这些对仍共享场景、时刻和A0，不能算85个独立试验。

逐一剔除任意一个场景后，动作模型的全部候选差分误差均仍低于不变基线（10/10种剔除情况）。它不再像上一轮那样，去掉task03就失去全部平均差分优势。这是事后描述性稳健检查，不是独立统计确认。

## 平均改善没有解决哪些问题

**动作无明显影响时仍有虚假变化。** 真实候选差异≤1mm的开发对，不变误差0.035mm，动作模型1.884mm；物体自身近不动的窗口，不变误差0.067mm、动作模型2.498mm。差分预测用于干预前仍需处理这类误差。

**闭夹爪配方反而更差。** 在该类别20对中，不变差分误差1.315mm，动作模型4.592mm。开夹爪和六种平移扰动类别均有平均改善，不代表所有动作类型已经可靠。不能用总体均值遮盖闭夹爪的退化。

**事件成绩的有效支持非常小。**

| 开发集事件变化 | 正例分支 | 来源场景/时刻 | 动作模型TP / FP / FN |
|---|---:|---|---|
| 持续抓持形成 | 8 | 仅task03_init34，t64 | 8 / 0 / 0 |
| 持续抓持消失 | 1 | 仅task05_init34，t64 | 1 / 0 / 0 |
| 有抓持历史的释放静置形成 | 0 | 无 | 0 / 0 / 0；不可评价召回 |
| 释放静置状态消失 | 8 | task00/init34与task06/init34，t160 | 5 / 5 / 3 |

8/8的抓持形成不能说成8个独立场景成功。另一只碗仍没有持续抓持正例，不能声称目标身份交换/错误物体泛化已经验证。

## 需要修正的时间问题

v1静置事件用包含首尾11个采样点的10控制间隔窗口。若anchor=t时夹爪还接触物体，H8终点的窗口[t−2,t+8]仍包含该接触，因此`released_on_quiet`不可能成立，更严格的`release_after_attachment`也不可能成立。

即使t后立即脱离且始终安静放在盘上，t+10窗口仍包含t的接触；最早t+11才可能满足连续无夹爪接触。当前8步分支适合比较短期运动，不能完整覆盖从正在夹持到持续释放静置的确认过程。

这不意味着“所有H8释放形成都不可能”：若anchor之前已脱离，可能在后8步完成持续窗口。本批零正例也不全由窗口长度解释。但不能只重复收集相同H8来期待解决这类覆盖。已用合成记录核对：最后接触t64，quiet_on在t72/t74均假，t75才真；旧标签未修改。

## 下一项工作应该改变什么

先设计**按当前关系状态分层、具有较长已知动作计划的事件采集**：接近但未接触、双指接触、已脱离持有、已释放支撑等。采样只依赖起点及其过去，不能根据分支之后是否成功筛选；记录缺失分层并保留无变化、失败与反向转移。

为“释放后持续静置”设置足够长的观测/执行窗口，例如另行冻结H16或更长的完整开环动作方案，再检查是否覆盖所需事件。不能把8步之后由C0根据未来观测生成的动作冒充根时刻已知计划，也不应缩短旧稳定窗口来追认正例。

同时登记独立新场景确认，按原始场景而非anchor/帧分组。已有同步RGB是可复用基础，但当前模型输入仍为真实物理状态；自然感知训练和最小状态压缩需后续明确目标，不能由本轮均值直接授权闭环。
