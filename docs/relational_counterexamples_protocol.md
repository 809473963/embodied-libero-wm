# 动作后果与失败反例：固定时刻干预及同步观测协议

日期：2026-10-07。用户授权“开始”，承接上一轮关系动力学pilot。协议在本轮任何新分支执行前冻结。

## 本轮回答的问题

上次只在三个固定候选上得到初步动作条件信号，开发集大差异仅3对且收益受一个起点影响。本轮扩大动作后果、近不变后果与事件变化的可检验范围，同时补齐自然观测记录。动作配方并不保证产生某种失败；最终按实际记录报告缺失类别。

## 场景、时刻与动作

- 使用既有10任务各init31和34的A0完整轨迹，共20个旧场景来源。每个固定取第64、160步，各9条H8分支，共40个anchor状态、360条分支。
- 两个时刻与9种动作在看本轮结果前固定，不按候选收益、成功、接触或oracle分歧筛选时刻，不替换已经成功或无事件的时刻。
- fresh环境使用原seed和原初始状态，重放该A0轨迹从0到anchor的完整实际动作。A0方案为原记录的随后8步动作。
- 另外8种方案：保留A0六维手臂动作、夹爪全程设-1（开）或+1（闭）；以及分别在A0的三个平移控制输入上加/减0.2，其余维度不变，clip到[-1,1]。这里0.2是归一化控制输入偏移，不是0.2米。
- 不增加旋转或连续×夹爪组合，不搜索幅度，不按表现去掉重复配方。真实重复动作数另行报告。
- 分支在anchor+8结束，**没有新的300步续行或终局utility标签**。物理标签v1沿用，不改阈值。

这些新动作不局限于旧N64选择器，但仍是围绕既有C0轨迹的有限干预，不能称为摆脱C0分布或任意控制泛化。

## 数据与隔离

只用允许init-state容器行31–34的既有选择性解析器；实际场景用31/34。不会打开HDF5、demo36–49数值或新增场景。原始20个场景与模型开发都有历史关联，**本轮不是独立scene确认**。所有同场景的时刻/候选必须作为同一组；不能将40个anchor当40个独立新布局。

按控制步记录物理状态、全部接触及wrench、完整动作。自然观测为初始帧0，加anchor前10步至anchor+8（共20帧128×128 RGB与12维proprio），使用显式global step对齐。长期身份可用初始帧；这不是完整episode视频，也不是长时记忆已经可学的证明。

自然RGB通过与已安装robosuite同一相机和翻转约定直接render，不刷新观测缓存或改变动作计划；proprio按原EEF、夹爪qpos、关节qpos顺序直接读。每条分支的anchor/H8与原snapshot接口逐项比较。物理记录用于训练标签和本轮冻结模型评估，未来自然模型输入不能混入物理真值。

官方success只记录为原环境接口诊断；不参与样本挑选、阈值或训练。某种反例仍缺失时明确报告，不能把未观察到误抓当作识别能力。

## 技术preflight与预算

第一个场景`task00_init31`、anchor64先执行三次相同A0：两次开RGB录制、一次关闭RGB录制。完整物理数组必须逐项完全一致，两次RGB/proprio也完全一致；所有A0前缀及H8物理字段必须与旧记录一致。该试验只核验技术，不选科学样本。

三次preflight额外216控制步。正式360条分支包含全部fresh prefix重放，共43,200步。**总上限363次运行、43,416个控制步**；四个隔离进程，无在线C0模型推理。预算在提交每批执行之前记账，失败部分也计入，不自动重试/重置预算。任何身份、接触、时序、渲染一致性失败都停止，保留证据。

## 完成后的冻结模型检查

完整采集后先验证哈希、接触重建、动作配方、自然帧时间戳、标签v1及同anchor历史完全一致，再使用上一轮6个固定checkpoint及原fit归一化计算三seed平均预测。不重训、不校准、不挑新阈值。

分别报告旧fit来源init31和已暴露development来源init34。主要指标：目标—盘/夹爪位移误差、各干预相对A0的后果差分误差（全部、真实>1mm、≤1mm分层）、事件发生/消失precision/recall及分母、另一只碗正例覆盖。1mm分层沿用既有pilot，仅作描述。

新的干预动作分布与旧三个候选不同；退化应解释为该扩展分布上的预测不足，不自动证明模型结构错误。泛化证据仍需另注册真正独立的新场景。新场景、进一步训练与闭环不在当前后台执行链中。
