# 统一对象位置与独立关系：旧场景匹配实验协议

日期：2026-10-09。依赖统一节点审计 v3 完整通过数据验证。只使用旧13场景4,843帧；原3折scene划分保持。不得读取已暴露9开发场景或40确认seeds。无环境动作、事件训练、动力学重训或controller。

## 假设与输入

共享对象位置能否同时降低所有关键几何关系的误差，而不仅让关系按构造闭合？输入为初始RGB和当前RGB（各64×64）、合法12维proprio及上一动作7维。没有语言、真值姿态/速度/接触输入；固定物理槽位不等于语言grounding。初始加当前两帧不是完整时间记忆。

8个环境对象位置加合法测量grip为9节点，36条i<j边。两碗、plate、cookies、ramekin为主要对象组；table/cabinet/stove单列context。关键边是前5对象彼此以及各自到grip共15边。操作参照plate不因移动量小就排除。

## 匹配实现

相同CNN与融合层：6→16→32→32卷积，8×8特征压到64，拼19维输入后128隐藏层。共享头输出8×3 world位置，grip来自合法测量，边由节点相减；独立头输出36×3边。公共层初始化和batch顺序相同，输出头参数量不同并明确报告。两者均只用同一关系loss，无额外共享位置监督或mask辅助。

输出中心是每fold拟合场景等权平均，残差单位固定50mm；两者关系loss均在50mm尺度计算SmoothL1，不使用每边不同尺度。三组边loss各占1/3：含前5对象的环境边、8条robot边、3条纯context边。组内平均；scene按帧数倒数加权，避免长轨迹主导。observation标准化只用fold fit，std下限0.001。

旧3折×seeds11/23/47×2结构，共18fits；40epochs，AdamW lr0.001/wd0.0001，batch128，gradient clip1。只取最终epoch，不选checkpoint或调权重。GPU不允许TF32，确定性算法；参数、归一化、预测与runtime落盘。

## 评价与预定决策

scene-macro逐节点位置、36边误差、3组误差、15关键边均值、每帧最坏关键边、84个三角闭合。独立边模型的节点展示统一用object→grip边加合法grip恢复，不进行闭合投影。ensemble和全部seeds都报。

优先共享结构的内部工程线：至少2/3seed的关键边均值和每帧最坏关键边均改善≥10%，且任何单条关键边均值不恶化>10%。这是资源分配线，不是信息是否存在的科学边界，不自动授权外部确认或控制。共享闭合接近零不算通过证据。未通过保留两者结果，不增加seed或改loss寻找通过。

本轮是位置结构对照。后续仍须补充分层遮挡、接触/运动、身份歧义、姿态/速度、及接冻结事件读出的评估，不能以本轮位置结果冒充事件可靠性。13旧场景被反复使用，不作独立泛化主张。

附加固定无图像基线：每fold仅用fit场景等权对象平均world位置，加合法grip构造全部边；不拟合额外参数、不选超参，与两模型逐项比较，防止把固定布局记忆误认为视觉感知。
