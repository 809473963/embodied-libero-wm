# 多物体关系感知：现有能力审计协议

日期：2026-10-09。用户要求扩展至任务相关对象及关系。

范围：沿用9个已暴露开发场景22个不同root起点；不新增训练、仿真或确认集。现有自然感知直接输出两碗相对盘/夹爪共四向量；辅助uv/depth头输出两碗和盘的三个位置。评估所有已覆盖关系，并登记未预测的对象和状态，不虚构完整scene graph。

固定指标：逐对象与逐关系scene宏平均3D误差、各轴MAE、每起点最坏直接关系误差；两碗间和夹爪—盘关系分别从两条路径推导。使用真实夹爪旋转仅作局部→世界评估转换。闭合残差为(a−b)−R(c−d)，真值闭合必须通过；同一个残差不重复记作两种独立证据。

辅助共享位置只评估三对象三对关系；不混入GT夹爪位置声称实现四对象自然感知。共享位置的三角闭合是代数性质，不是准确性证据。

额外诊断：四个world向量等权投影到闭合约束。明确它依赖真值旋转，且总体平方误差不增加是数学保证，不是模型学习或部署结果。禁止用其效果调整训练或阈值。

完整性清单覆盖目标、另一碗、盘、夹爪、记录中的其他对象/支撑；检查位置、姿态、速度、身份、接触/支撑和不确定性。未来事件头不视作当前状态感知。所有缺项标明unmeasured。

输出报告、指标、可复算数组和验证记录。没有新继续阈值、checkpoint选择或controller授权。
