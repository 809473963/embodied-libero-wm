## 同一起点的动作差异

比较A0与候选49/50的真实H8终点：40起点中仅**6个**至少有一个操作性事件标签不同；**15个**至少有一组目标相对盘位置差超过1mm。1mm只是本次描述性统计分层，不是新成功门槛，也未用于筛选训练起点。

这说明连续关系变化比离散事件提供更密的学习信号。不能只训练事件分类后以高accuracy宣布学到了动作效应。候选0/49/50覆盖有限，不能推断完整N64或任意动作的可预测性。

## 下一项最小试验的设计约束

问题限定为：**给定真实当前关系及历史、已确定的未来动作块，能否预测物体关系怎样改变，并优于不变/无动作基线？** 先隔离动力学，不将视觉误差混入；这不是最终部署输入。

1. 监督连续目标—盘、目标—夹爪的相对位移变化，并辅助预测接触及v1事件；保留另一只碗的关系负例但不宣称其正例能力。未知标签必须mask，不能当负例。
2. 输入仅含当前及过去关系/机器人状态和完整有序动作。使用已规划H8块的起点；**不能将之后由C0根据未来观测生成的反馈动作提前当作root已知输入**。长于8步的根时刻预测需另行定义策略条件或开环计划。
3. 按root绑定全部候选/片段；只用fit计算归一化与类别权重。开发集只作已暴露pilot比较，不据此声称跨任务迁移。共享prefix只保留一次或显式按root加权。
4. 固定小模型与种子预算，比较保持不变、同容量无动作、完整动作模型；同root动作置换作差分负控制。各模型不能获得不等价的历史/状态信息。
5. 重点报告相对位移变化误差、变化与不变分层、事件发生/消失precision-recall、同root候选后果差分保真。稀有开发事件计数很小，须报告分母与逐root结果；不以接近96%的普通accuracy作为成功标准。
6. 训练前再冻结具体输入列、网络、损失尺度、采样权重、种子、epoch与比较规则。若动作模型不能稳定胜过无动作/不变，应区分动作覆盖不足、物理状态压缩和模型拟合问题，不能归因为视觉backbone。

本轮完成覆盖复核，未启动训练。后续先落实以上训练协议及输入泄漏/分组检查，再运行固定小试验；自然感知、独立新场景和闭环控制仍是后续独立门槛。
