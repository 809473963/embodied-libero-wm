# 旧场景定位辅助监督对照：有限执行协议

日期：2026-10-08。训练与数据生成前冻结。

仅使用旧H24 manifest中的13场景、228分支。最多8,208个记录帧，按root/step/自然输入及标签hash去重；共享前缀不重复计样本。不读取新development分支或confirmation。按原seed重置模型，并对动作后帧逆转最后一次Euler积分，仅做静态render；每条去重帧重建RGB必须逐位相同，不同立即停止依赖训练并保留证据。无env.step控制。

监督：原18维两碗相对盘/夹爪几何与夹爪速度；额外3对象的物理body原点uv及camera depth共9维；可见对象mask按16×16块取均值，得到8×8面积比例。uv不是可见mask质心。无标签推理输入，固定物理槽位不代表语言grounding。

三折由13个root名称排序后序号模3决定；同scene全部帧/动作/初始图像必须留在同一折。三折皆仅拟合另外两折；归一化、mask类别权重fit-only，scene等权。跨折标签不得参与统计。旧scene是内部开发，不是假装重新变盲。

同架构网络：初始+当前64pxRGB六通道CNN16/32/32，8×8特征flatten→64；64+19维合法proprio/上一动作→128→18状态。附加64→9点/深度头和32→3的1×1 mask头。两组网络完全相同，只改损失：direct只用标准化状态SmoothL1；localized额外0.25×标准化点/深度SmoothL1+0.1×mask BCE。mask正类权重由训练像素比例算，截断1..20。该比较检验辅助定位监督，不是显式3D几何解算器。

2组×3fold×3seed(11,23,47)=18fits硬上限，40epochs，batch128，AdamW lr.001 wd.0001，梯度clip1。固定最后epoch，不选择最优seed/轮次。两组相同初始化及batch顺序。保存fold预测、OOF合并与3seed均值。

主要指标：13scene宏平均的目标—盘及目标—夹爪几何误差。继续线：至少2/3seed两项均比direct降低10%，另一碗两项均不退化超过10%。报告所有scene及seed，不做pair/frame伪独立置信区间。无gate后调参。

流水线自动顺序生成监督→18fits→OOF完整性/场景隔离/归一化复算→报告。技术失败保留现场，不盲重试。末端不打开新开发/确认集、不重训动力学、不接controller。
