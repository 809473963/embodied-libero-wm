# 新development关系研究连续执行协议

日期：2026-10-08。用户明确要求“一个完成继续下一步”。本协议将必要步骤接成有限、自动推进的研究链，不在每个正常阶段结束时等待确认。

## 顺序与边界

1. 在已生成且通过重放/布局检查的20个development场景上，各采集300步冻结C0轨迹，同步逐步物理状态与自然RGB/proprio。
2. 按当前和过去关系自动选取起点，先输出完整起点/缺失登记，再执行固定H24后果分支。
3. 核验分支、重算事件并分开实际持有→释放与已释放后的稳定窗口确认。
4. 用**全部旧H24数据**拟合固定小模型；仅用新development分支评估，不使用新数据拟合、归一化或选择训练轮数。
5. 从保存预测重新计算指标，自动生成最终报告与科学状态。

技术核验失败保留证据并停止依赖步骤，禁止自动重置预算或盲目重试。事件覆盖不足不伪装成学习失败：仍报告缺失；若无任何新起点，跳过训练并生成不足报告。正常完成后不再停在“等待下一次用户确认”。整条有限链完成后交付证据，不自动打开confirmation或无限搜索模型。

## C0与记录

仅使用通过新场景preflight的20份保存状态，每次fresh同seed构造、单次底层reset、恢复状态并检查初始pose/RGB/sim-state及G2身份。与此前preflight相同的控制器初始化契约，不把仅恢复中途qpos当作完整重放。

C0-v2 checkpoint不变，使用原padded batch8推理，每8步计划一次，到300步，成功后仍按既有诊断契约继续。所有成功和失败轨迹都保留，不按success选场景。第一场景额外做两次完整C0重复，三份动作/物理/RGB记录须完全一致。总22次轨迹、6,600控制步。

物理记录沿用实体pose/速度、机器人qpos/qvel、夹爪/实体接触、官方On等；RGB/proprio逐控制步对齐。官方success只作过程诊断，不作为训练目标或选起点依据。

## 起点分层与分支

在t=16,24,…,240取每层首次满足的时刻，层包括：

- 无夹爪接触且目标body原点到grip site≤0.08m的粗接近；
- 当前双指接触但v1 detached未成立；
- v1 detached成立且目标—盘XY距离>0.06m的持有远盘；
- v1 detached成立且XY距离≤0.06m的持有近盘；
- 当前无夹爪接触、On、非夹爪接触且过去观察过detached的释放在盘上。

0.06m是预先固定的几何分层线，不是成功门槛或可直接放置的证明；保留实际Z和完整物理状态。不使用未来后果挑样本，不保证每场景每层都有记录。同scene/time多层合并，缺失保留；所有片段跟随原场景分组。

每个起点沿用已冻结的6种完整H24方案：原H8接固定保持、保持、打开、闭合、抬升闭合、下降后打开；幅度0.15为归一化控制输入。第8步以后不根据未来观测重新调用C0。每条fresh精确重放C0前缀，核验直到起点的物理一致性；方案0的前H8还须与原C0一致。

第一起点额外3次相同H24重放；每批在提交前记预算。最多100个起点、603条分支、159,192控制步。实际起点选定后写入更紧的精确预算，禁止动态追加样本。轨迹＋分支总硬上限165,792控制步。自然分支记录初始帧及t−10…t+24。

## 模型固定预算

旧H24的228分支、13个旧场景全部作为old_fit；这些旧开发数据已用于大量设计，不再称独立验证。新的20场景只作development评估，没有重新拟合其标签或数据统计；本轮不是confirmation实验。

保持pilot的11步特权状态历史、GRU64、动作Linear32、联合Linear128头；动作输入由56维改为有序H24的168维。输出仍为两碗相对盘/夹爪的12维位置变化及18个接触/事件终点。丰富qpos/qvel、真实接触和持久身份仍是特权输入，不声称已学自然感知。

无动作对照使用相同结构并将标准化动作置零；另有不变基线。两模型×种子11/23/47共6次拟合，每次80 epochs、batch128、AdamW lr0.001、weight_decay0.0001、梯度裁剪1。连续SmoothL1+0.2×已知标签BCE；旧fit计算所有归一化、增量尺度和截断[1,20]的正类权重。按原scene总权重相同，不按分支数量偏重某scene。未知mask不作负例；无epoch/seed筛选。

主要指标：新development按scene宏平均的目标—盘/夹爪连续误差、同anchor各方案相对方案0的后果差分误差（先场景内平均，再跨scene平均），事件发生/消失precision/recall及场景支持。最终均值ensemble预先声明，同时保留全部逐seed结果。

有限继续线：新development至少5个有起点场景，且至少2/3个seed同时满足两项连续误差均低于无动作/不变基线、场景宏平均候选差分误差改善至少10%，才记录H24动作条件支持。否则如实记录未建立优势，不自动调参。无论是否通过，完整释放可靠性须单独看“起点仍持有→静置”的场景数，不能用已经释放后的计时确认补足。
