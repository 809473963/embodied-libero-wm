# 关系与事件标签 v1：因果定义和已有记录检查

日期：2026-10-07。

**已完成操作性标签 v1 的实现、冻结与提取。标签能够计算，但现有4个起点不足以进入可信的关系动力学训练评估。** 下一步正在补录其余36个旧起点，扩大覆盖后再决定最小训练试验。

## 标签究竟表示什么

目标是学习物体间的关系及动作引起的变化，事件只是这些关系的时间摘要，不是三个固定奖励或强制执行顺序。输出同时保留全部8个实体两两相对位置、相对线速度、实体接触、夹爪接触以及两只碗各自的夹爪局部位置。标签独立计算两只碗，语言指定的目标身份沿用初始场景持久身份。

| 操作性标签 | 当前时刻成立所需证据 | 不支持的强解释 |
|---|---|---|
| `bilateral_attachment` | 过去10个控制间隔的11个采样点均双指腹接触，物体在夹爪局部坐标相对窗口起点漂移≤5mm | 不证明已经离开桌面、不滑移或可以承受任意后续动作 |
| `detached_attachment` | 上一条件加整个窗口没有任何非夹爪接触 | 不证明表面净空充分，也不保证窗口之后不掉落 |
| `lift_hold_evidence` | 上一条件加窗口内最低物体原点高度比窗口前最后一次非夹爪接触时高>5mm | 非夹爪接触未证明承重；物体原点高度不是表面净空 |
| `released_on_quiet` | 整窗官方On成立、无夹爪接触、有非夹爪接触；线速度<0.02m/s、角速度<0.5rad/s、位置漂移≤5mm | 不证明此前由机器人放下，不等于未来永远稳定 |
| `release_after_attachment` | 上一条件加窗口开始之前已观察到`detached_attachment` | 表示观察到抓持后释放放置证据，不证明完整因果归因 |

“非夹爪接触”包括记录到的其他几何接触，可能包括机器人非夹爪部分；不把它直接命名为“支撑”。接触力和接触坐标系仍保存在原始记录，尚未以其建立承重真值。低角速度用于物理静止，不把对称碗的绝对朝向当作语义目标。

10个控制间隔在20Hz下名义为0.5秒。阈值是明确的工程约定：继承原预检查的时间/位移量级，额外限制释放后的角速度和位置漂移；未根据最终success优化。原数据已被查看，本次冻结不构成盲验证或证明这些阈值跨物体普适。

## 时间与未知值

- 标签标在窗口**结束时刻t**，只使用`t`及以前的记录；前10个样本没有完整窗口，标`-1`未知。
- `0`只表示操作性谓词不成立，不表示已经证明“物理上不能稳定抓取”。
- 脱离接触后若没有可观察的先前高度参照，抬起标签为未知；静置在盘上但没有先前脱离抓持证据时，释放转移标签未知。
- 从未知变为真不计作已经观测到的“假→真”事件起点；减少录像从中途开始造成的伪事件。
- `actions[t]`连接状态`t`和`t+1`。另存未来1/8/20步终点标签，尾部截断为未知。这些未来标签仅作监督，不能进入当前模型输入。
- 同root共享prefix去重，所有候选、相邻时间窗和历史必须随root分组，禁止随机按帧拆训练/开发。

## 检查与当前瓶颈

7项新测试通过：截断输入与完整输入的过去标签一致、未来监督的右截断、接触中断/夹爪相对漂移、抬起参照缺失、持有或旋转不算静置、释放需要先前脱离抓持、平移及绕竖直轴旋转的一致性、两物体身份分离、非连续控制步拒绝（部分合并在同一测试中）。连同既有5项密集窗口测试，合计12项通过；没有重跑全仓库套件。

**当前首先缺的是足够广的关系变化实例，而非已经证明模型学不会。** 技术和合成反例测试不能代替跨场景人工/独立真值核验。尤其另一只碗没有正例，无法评价错误物体抓取的真实识别能力；也没有逐步对齐的自然RGB，不能把特权状态标签当作自然观测训练已经就绪。
