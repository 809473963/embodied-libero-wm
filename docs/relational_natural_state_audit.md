# 自然观测→关系状态→冻结动力学：首轮试验

日期：2026-10-08。**NATURAL_STATE_PILOT_BRIDGE_NOT_ESTABLISHED**。

目的：把感知误差实际接入已学到的动力学，而不是只看视觉回归分数。该结果仅针对固定小CNN和当前数据，不证明视觉信息存在或缺失的普遍结论。

数据：旧13场景、4843条去重观测训练；新9场景、2812条观测开发评估。相同场景的共享分支前缀去重；帧数不是独立场景数。无确认集访问。

图像模型输入初始自然RGB与当前自然RGB（固定缩至64×64）、当前12维合法proprio及上一7维动作；对照只用proprio与上一动作。输出两碗相对盘/夹爪12维位置与夹爪6维速度。每个时刻只用该时刻及之前输入，训练监督可以来自旧轨迹后段；未来图像不进入当前预测。

每种输入3种子×40轮，无最佳epoch选择。预测状态按11步组装，替换26维geometry_history模型的18个状态量，上一动作及有效位不变；冻结3个动力学模型并平均其预测，不重新拟合。

## 固定继续线

至少2/3视觉种子在未来目标—盘、目标—夹爪与候选差分三项均较对应proprio模型改善10%，且低于真实当前状态的不变基线。该线衡量是否值得继续此自然输入桥，不是控制安全、语言理解或跨任务泛化认证。

## 解释范围与后续

两个碗按固定物理身份槽位监督，初始图像用于保留场景参考；未输入语言，也没有独立证明从相似碗视觉恢复持久身份。所有标签是训练时的特权监督；推理特征不含真实几何/接触/事件。夹爪速度也由自然输入预测，没有偷偷保留真实速度。

该初始+当前帧CNN不具备可学习的完整时序记忆；下游11步动力学历史不等于感知层已解决遮挡身份。因此失败可能来自容量、观测、身份或数据覆盖，不能重启“frozen backbone无信息”的结论。

未通过时保留该负结果，下一轮应先分解当前几何/身份误差与动力学分布偏移；用旧场景内部的输入对照诊断，不以新开发集反复调模型，也不直接增加仿真或打开确认集。
