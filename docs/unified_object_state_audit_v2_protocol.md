# 统一节点监督与合法FK审计协议

日期：2026-10-09。仅旧13场景4,843去重帧，与旧localization_cv的行序和scene folds精确对齐。无训练、无env.step、无新开发/confirmation访问。

读取原8实体pose(位置、wxyz姿态、线/角速度)、接触、双指垫接触、外部接触、两碗官方On和grip frame。按manifest几何实体顺序检查identity，验证有限值、姿态单位长度、旋转正交性、接触对称。构建9节点world位置与36个i<j无向关系标签，不重复反向边。

合法FK：仅使用12维proprio中的7关节位置及2夹爪位置，通过同任务固定机器人模型forward，不读取真值qvel/物体位置/真值grip姿态作为FK输入。每场景按原seed reset复原模型级常量，检查机器人base校准跨场景相同；禁止将场景特权变化藏入FK。全4,843帧检查位置/旋转误差。预定最大位置1mm、旋转0.5°为工程继续线；记录完整分布，不当精确复原或统计泛化证明。

位置层训练可优先用合法EEF直接测量，不依赖FK旋转。若FK精度线未过，不阻止无需姿态的world位置对照，但不得宣称机器人旋转契约已通过。无qvel回退或误差阈值调整。

静态与移动节点的位移范围、可见mask覆盖与接触语义分别登记。接触不等于有向支撑；只有两碗—盘有现成On。原始标签可得不代表自然感知已学到或观测充分。

输出节点标签、来源hash、全帧FK误差、报告；复算36条边及84个三角闭合。发生数据或技术错误保留现场并停止依赖训练。

## v2 技术修正

v1 在监督对齐检查停止：float64 原始 proprio 转为数据集 float32 后，关节值的舍入差可超过绝对 1e-7。本版按数据集 dtype 转换原始记录，再要求逐元素精确相等；不是放宽科学误差线。保留原失败输出。其余范围及 FK 预算不变。
