# 最小关系状态消融协议

日期：2026-10-08。执行前冻结。用户已授权自动推进。

目的：在原动作条件H24优势基础上，检验紧凑关系状态是否保留该信号；不用当前开发结果挑训练epoch、温度、种子或追加输入。

固定输入四组（包含末尾历史有效位）：

| 组 | 维度 | 历史 | 输入 |
|---|---:|---:|---|
| geometry_history | 26 | 11步 | 两碗相对盘/夹爪位置12、夹爪速度6、上一执行动作7、有效位1 |
| contact_history | 34 | 11步 | 上述+两碗任意夹爪接触2、双侧指垫接触4、外部接触2 |
| memory_history | 40 | 11步 | 上述+两碗因果高度参考/参考已知/曾detached共6 |
| memory_current | 40 | 1步 | 上组当前值，仍含因果记忆与上一动作 |

不输入官方On、当前事件标签、全世界绝对pose、全接触矩阵、机器人qpos/qvel。记忆仍是特权因果信息，不声称自然感知可得。现有完整522维结果作为原样参考；输入大小变化也改变参数量，因此该消融不单独识别信息与容量效应。

数据：冻结的relational_autorun/models/dataset.npz与原meta/schema。旧H24的13场景228分支fit；新9个可用场景132分支development；其余11个无合格起点的布局不补采。所有同场景分支保持同split。开发集已被审视，不作独立确认。确认40个seed不访问。

训练：四组×动作/无动作×种子11/23/47=24次；GRU64、动作编码32、联合头128、80epochs、batch128、AdamW lr0.001 wd0.0001、梯度clip1。损失连续SmoothL1+0.2已知标签BCE，正类权重clip1..20，场景均衡。每组归一化仅旧fit，未知不当负例。无动作模型将标准化动作置零。保留所有种子和固定均值ensemble，无自动搜索或重试。无新增仿真。

执行前固定继续线：每组至少2/3种子同时满足：两项场景宏平均连续误差低于该组无动作及不变基线，候选差分误差低于二者最优的90%；且上述三项误差不超过原完整模型同种子的110%。这是资源分配线，不是等价性显著性检验。不能用单个获胜指标替换联合线。

额外诊断：真实位移≤1mm分支的误动；On、attachment、lift、quiet/release的发生误报；root已detached后的真正释放预测，真实正例场景数单独保留。事件可靠性和控制收益不由连续误差门槛自动授权。

输出：results/relational_minimal_state/runtime.json、各组checkpoint/预测/normalization、evaluation、review和validation；docs/relational_minimal_state_audit.md。自动完成训练后从保存预测复算108组指标、归一化与输入哈希。任何技术错误停止依赖步骤并保留现场。模型预算结束后交付结果，不无限训练。

若有组保留信号，下一研究问题是自然观测恢复必要变量；若无组保留，先在旧数据内部定位被移除的姿态/速度/机器人信息。不打开确认集，不直接接学习式controller。
