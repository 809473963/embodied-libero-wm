# 自然关系状态恢复与冻结动力学替换协议

日期：2026-10-08。训练前冻结；有限自动链，用户已授权持续推进。

问题：自然观测的关系恢复误差会否吞没已验证的动作后果差分？不用普通回归精度替代闭环后果精度。

数据仅旧H24 228条分支、13场景作为fit，以及已暴露的新开发132分支、9场景作为development。每条使用已保存初始RGB及自然step的RGB/proprio，均核验原始数组哈希。共享前缀按(root,step,input+target hash)去重；有别名标签保留。所有来自同场景的帧不跨split。目标12维关系与6维夹爪速度取相同control step；上一执行动作来自step−1；禁止未来图像。分支预测仅使用root之前的11步输入。后续帧可以作旧fit监督，不能进入该分支root输入。

初始+当前自然RGB经固定2×2 box缩至64×64；输入12维proprio、上一动作7维，无任务ID、step、成功、事件或真实状态输入。两物理碗槽位由监督约定，初始图像作为身份参考；没有语言grounding主张，不宣称身份问题已解决。

两个模型：proprio/action小MLP；初始+当前RGB（6channels）三层CNN 16/32/32、flatten→64，与同19维自然输入拼接后128→18。小CNN从头训练，不下载或微调大模型。种子11/23/47、40轮、batch128、AdamW lr0.001 wd0.0001、clip1、标准化目标SmoothL1；归一化fit-only，各scene总权重相同。固定末轮与3种子均值，无epoch、seed、阈值选择。6次拟合为硬上限，不自动追加。

桥接：每个感知模型及其ensemble都替换已冻结geometry_history的12维关系及6维夹爪速度，合法上一动作与valid不变。冻结3个动力学模型ensemble输出，不调整动力学。比较真实状态参考、proprio、RGB+proprio。

三主指标：新开发按scene宏平均的绝对未来目标—盘/夹爪误差，以及相同root不同动作的差分误差。未来位置必须加上预测当前关系，而非只报告预测Δ。另报告当前关系误差、近静止误差、On/release事件误报。

继续线预定：至少2/3视觉种子在上述三主指标均较对应proprio种子改善至少10%，且低于真实当前关系的不变基线。此线只是投入规则；未过不证明RGB无信息，通过不授权controller。该批开发集已被查看，禁止称独立确认。

计算预算：6个小模型×40轮；无新仿真、无新数据访问范围、无确认集、无学习式controller。自动流程为数据核对/去重→训练→冻结动力学替换→保存预测独立复算→报告。技术失败保留现场并停止依赖任务，不盲重试。结果写results/relational_natural_state/runtime.json及docs/relational_natural_state_audit.md。
